# Niharika Srinivas — Portfolio

Dark developer-focused job-search portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

Edit `data/portfolio.ts` for experience, skills, projects and links. Replace `public/images/profile.jpg` if needed.
